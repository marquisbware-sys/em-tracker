How it works: GitHub Actions runs Friday after the close and Sunday evening. It pulls option chains from yfinance, calculates EM as ATM straddle × 0.85, and finds the 0.16 delta strikes using each strike's own IV (so skew is captured). Bands are anchored to the last completed weekly close, not live price.
Skew row: how far each Δ16 strike sits beyond its EM band. A wider put gap than call gap means the market is paying up for downside.
Pine: the copy buttons build the 8-field string TICKER:wEM:mEM:ref:wD16C:wD16P:mD16C:mD16P for the indicator's EM Watchlist String input. Flagged (suspect) tickers are left out.
